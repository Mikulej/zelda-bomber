## Requirements

- Python 3.14.5  
- `pip install -r requirements.txt`  
- Pygame dependencies (check below)

### Pygame dependencies

Make sure you have all needed libraries for running pygame.

**Linux (Ubuntu 26.04 LTS)**

```bash
sudo apt-get update
sudo apt install --fix-missing libsdl1.2-dev 
sudo apt-get install git python3-dev python3-setuptools python3-numpy python3-opengl \
libsdl-image1.2-dev libsdl-mixer1.2-dev libsdl-ttf2.0-dev libsmpeg-dev \
libsdl1.2-dev libportmidi-dev libswscale-dev libavformat-dev libavcodec-dev \
libtiff5-dev libx11-6 libx11-dev fluid-soundfont-gm timgm6mb-soundfont \
xfonts-base xfonts-100dpi xfonts-75dpi xfonts-cyrillic fontconfig fonts-freefont-ttf libfreetype6-dev --fix-missing
```

**MacOS 15.7.4**
```bash
brew install sdl2 sdl2_image sdl2_mixer sdl2_ttf pkg-config
```
